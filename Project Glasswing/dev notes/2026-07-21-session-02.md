# Project Glasswing — Dev Notes, Session 2
**Date:** 2026-07-21 · **Focus:** Milestone 2 — G3X-style touch display redesign · **Status:** ✅ built & smoke-tested

## What was built

`glasswing-ui/` — a complete reimagining of the display in the **Garmin G3X Touch**
idiom (reference: user screenshot 2026-07-21), as a zero-dependency web app for
touch/iPad use. Supplements pyEfis (which remains the Pi cockpit path).

- `server.py` — WebSocket bridge (:8760) with three pluggable sources:
  - `NetfixSource` — subscribes to FIX-Gateway (:3490) keys PITCH/ROLL/HEAD/IAS/
    ALT/VS/GS/LAT/LONG/RPM/MAP/OILP/OILT/FFLOW/VOLT/OAT → works with ArduPilot
    SITL today, SpeedyBee F405 later (same bytes).
  - `MsfsSource` — **MSFS dev-testing stub** (per user decision: Microsoft Flight
    Sim for initial dev testing instead of SpeedyBee; SpeedyBee stays the
    practical/flight path). SimConnect read points marked `TODO(msfs)`; falls
    back to synthetic flight until wired.
  - `SimSource` — synthetic flight (orbits/climbs) so the UI is always demoable.
- `static/index.html|css|js` — canvas-rendered display:
  - Synthetic-terrain PFD (fbm-noise terrain, roll/pitch ladder, magenta
    approach-pathway boxes), airspeed tape + bug, altitude tape + VSI strip +
    BARO MIN, heading strip with DTK bug, HSI with inset moving map.
  - Left engine strip: RPM/MAP dials, OIL PSI/GPH/OIL°F, CHT/EGT bar quads,
    fuel L/R, volts.
  - Top bar: COM1/NAV1/COM2 active+standby (tap freq = swap), DTK/TRK chips,
    xpdr N675PD 3422 ALT + IDENT, audio. Bottom bar: leg, DIS/ETE/ETA, timer,
    UTC, OAT.
  - Right column: top-down synthetic map (range rings, ownship, waypoints),
    HSI rose with CDI, nearest-airport list.
  - **Tap the map inset (or Split button) → split screen: PFD left, expanded
    map right** (user-requested interaction).
