Six bugs between "clone" and "it works"

1 · RPi-only deps broke the macOS install — lgpio needs swig, smbus needs linux/i2c.h.
→ Moved to a [rpi] pip extra; real Pi behavior unchanged (patch 0001).
2 · mavlink plugin was serial-only — it stat()ed device nodes; SITL speaks UDP.
→ Taught Mav.py udp:/tcp: network links, baud-free (patch 0001).
3 · Launcher not idempotent — re-runs redid setup after failures.
→ Keyed off init.marker instead of venv presence.
4 · pyEfis crashed on xwininfo — the Android/Weston screen is X11-only; dock icon bounced forever.
→ Weston instrument now degrades to a placeholder (patch 0002).
5 · syslog traceback spam — FIX-Gateway logged to /dev/log, a Linux-only socket.
→ Launcher drops the syslog handler in the seeded macOS config.
6 · Fullscreen PFD with no escape — screenFullSize:True = no window chrome.
→ Windowed 1280×800 dev mode; fullscreen stays one flag away for the cockpit (patch 0003).
